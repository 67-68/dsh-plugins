# auto-compression-and-accumulation

## Project Overview

mode-gate 是一套工作流/状态门禁系统：通过 mode-gate-overview 组织各阶段（state）能力，并以 feature intent 记录需求意图。本 overview 下当前包含 auto-compression-and-accumulation 意图，目标是在阶段推进中引入上下文自动压缩与阶段成果累积能力，同时由阶段门禁约束其可执行范围。架构 section 尚待 ACCUMULATE 阶段沉淀。

### Agent 理解

本需求属于 mode-gate 工作流的能力扩展：在阶段（state）推进过程中，对上下文/产出进行“自动压缩”与“累积”两条并行的能力沉淀。

拆解为以下模块级目标：
1. 自动压缩上下文设置页 —— 用户可配置“何时压缩、压缩到什么程度”的入口与参数呈现（模型压缩上下文设置）。
2. 压缩决策引擎 —— 依据当前上下文体量与阈值，自主判定是否触发压缩，并给出压缩结果态。
3. 累积沉淀机制 —— 阶段推进时把关键结论/架构/意图沉淀进 overview 链，形成可复用、可回溯的累积产物，而非每次从零开始。
4. 阶段权限门禁 —— 压缩与累积动作受当前 state 门禁约束，只有在允许的状态/阶段下才能执行，非法调用被拦截。

以上四个模块相互解耦：设置页负责人机配置面，决策引擎负责运行时判定，累积机制负责长期沉淀，门禁负责权限与边界。不得在本阶段臆测具体 API、文件路径或数据结构。

### 用户可见行为

用户在工作流中推进阶段时：可在一个集中设置页配置自动压缩的触发与强度；系统在上下文达到阈值时自动完成压缩而无需手动干预；阶段产出的关键结论会被累积到 overview 链中，后续阶段可直接读取复用；当处于不允许压缩/累积的阶段时，相关动作会被门禁拦截并给出明确反馈。

### 功能意图

为 mode-gate 工作流提供上下文自动压缩与阶段成果累积能力，并受阶段门禁约束。

### Checklist

- [ ] 模型压缩上下文设置页：用户可在集中入口配置自动压缩的触发条件与压缩强度，配置项生效
- [ ] 压缩决策引擎：上下文达到阈值时自动触发压缩，并输出确定的压缩结果态
- [ ] 累积沉淀机制：阶段推进时关键结论被写入 overview 链，后续阶段可读取复用
- [ ] 阶段权限门禁：仅允许的状态/阶段可执行压缩与累积，非法调用被拦截并反馈
